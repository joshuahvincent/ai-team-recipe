# A Recipe for Setting Up Your AI Team

A single markdown file that sets up a small team of Claude Code agents for your project, with working rules built in. Written for product managers, designers and engineers who are just getting started with AI. You don't need to code.

## How to use it

1. Make a folder for your project, or open an existing one.
2. Save [`RECIPE.md`](RECIPE.md) in that folder.
3. Open Claude Code in that folder.
4. Say: **"Read RECIPE.md and follow it."**

Claude interviews you, proposes a team, waits for your yes, then writes the files. Nothing is pushed, published or posted along the way.

## Status

Version 0.1, a draft. I haven't yet run it end to end in a fresh folder, so expect rough edges. If something breaks or confuses you, please open an issue.

## Background

This grew out of the team structure I described in [Building the Team That Built Wild Atlas](https://www.linkedin.com/pulse/building-team-built-wild-atlas-joshuah-vincent-vaksc/).
